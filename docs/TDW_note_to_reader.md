# A Note on Using This Book

This book is built to be read twice.

The first time through, the framework arrives in pieces. Ten dimensions in Part Two, twelve domains in Part Three, thirty-six stratagems in Part Four. Each is defined before it is used, and each case in Part Five is then read through all three at once. That order is deliberate. You cannot see a campaign until you have the vocabulary for its parts.

But a first reading can only show you the framework applied. It cannot show you the framework working, because working means recognizing a pattern before someone points it out.

So the cases are written to be returned to.

Each one runs the complete apparatus — every dimension, the relevant domains, the stratagem spine — even where two or three dimensions carry most of the weight. That completeness is not thoroughness for its own sake. It is scaffolding. On a second pass, having finished the book, you will find details in each case that the first reading had no place to put. A financing structure that now reads as Gradient. A timing choice that now reads as Phase. A concession that now reads as Agency capture, made years before anyone noticed the capture.

Those details are not errors of omission on my part. Many of them are in the text already, doing quiet work. Others are in the sources, waiting. The framework is designed to hold more than any single account of a case can carry, and the reader who comes back to Taiwan or Hong Kong or the Borrowed Knife with the whole apparatus in hand will see more than the chapter states.

That is the intended use. Read it once to learn the instrument. Read the cases again to use it. Then read the news.

The final test of a framework is not whether it explains the cases an author selected. It is whether it explains the case the reader finds tomorrow, in a domain this book never named, run by an actor this book never mentioned. If it does that, it was worth building. If it does not, no amount of documentation here will save it.

---

*A note on what is documented and what is argued.* Every part closes with a Sourcing Status section that separates three things: claims resting on primary sources, claims stated as inference and labelled as such in the text, and claims that could not be sourced to publication standard and were narrowed or removed rather than run unsupported. Where a famous figure turned out to have been famous as propaganda, it is reframed and the reframing is stated. A book about information warfare cannot repeat an information operation as an engineering statistic.
